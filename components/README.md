# Componentes de Interface (`/components`)

Este diretório armazena todos os componentes reutilizáveis da interface do **Alien OS**, organizados segundo os princípios de atômicos e módulos do Design System.

## 🎨 Organização de Arquivos

- **Componentes Base**: `Button.tsx`, `Badge.tsx`, `Card.tsx`, `SectionTitle.tsx`, `MetricCard.tsx`, `QuickActionCard.tsx`, `PageContainer.tsx`.
- **Layout Shell**: `Sidebar.tsx`, `Header.tsx`, `icons.tsx`.
- **Componentes do Domínio de Clientes (`/components/clientes`)**:
  - `AbductionJourneyTimeline.tsx`: Visualizador dos 8 estágios da Jornada de Abdução.
  - `ClientIntelligencePanel.tsx`: Diagnósticos da IA autônoma para cada cliente.
  - `ContractedServiceCard.tsx`: Cards dos serviços contratados.
  - `ActivityTimeline.tsx`: Linha de histórico de atividades.
  - `ClientDocumentsCard.tsx`: Central de documentos e briefings.
